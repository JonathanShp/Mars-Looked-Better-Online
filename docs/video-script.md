# MarsCuff: 30-second video, step by step

The video is a screen recording of the MarsCuff website. **No Minecraft needed.**
The **▶ Demo** button plays the whole story by itself in about 29 seconds, with big captions.

## How to record (Windows)

1. Open MarsCuff in Chrome (the GitHub Pages link, or `python -m http.server 8765 --directory web`
   and then http://localhost:8765).
2. Press **F11** so the browser fills the screen. Wait until the map has loaded.
3. Start recording: press **Win + Alt + R** (Xbox Game Bar). Or open **Snipping Tool → Record → New**
   and select the whole screen.
4. Click **▶ Demo**. Don't touch anything for 30 seconds.
5. Stop recording: **Win + Alt + R** again (or the Snipping Tool stop button).
   Game Bar saves the video in `Videos\Captures`.
6. Trim it to **30 seconds or less** (Clipchamp or the Photos app → Trim).
